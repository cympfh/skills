# vs-codereview

PR レビュー指摘を読み、妥当性を付けて一覧し、**番号指定されたものだけ**直す。

## 手順

### 1. PR を特定する

1. ユーザーが PR 番号 / URL を出していればそれを使う
2. なければカレントブランチの PR:
   ```bash
   gh pr view --json number,url,title
   ```
3. 見つからなければ止めて聞く。推測で別 PR を開かない

### 2. レビューコメントを読む

Copilot 含む全レビュアー。インライン・レビュー本体・outdated も対象。

```bash
# レビュー一覧
gh pr view <n> --comments

# インラインコメント（レビュースレッド）
gh api repos/{owner}/{repo}/pulls/<n>/comments --paginate

# 必要ならレビュー本体
gh api repos/{owner}/{repo}/pulls/<n>/reviews
```

`{owner}/{repo}` は `gh repo view --json nameWithOwner -q .nameWithOwner` で取る。

### 3. 指摘を一覧にする

内容でまとめる（同一指摘の重複は1件にまとめてよい）。

- **対応済みの指摘は一覧に含めない**（コード側で既に直っている・スレッド上で対応完了が明らかなもの）
- 妥当性が「無視」でも、未対応なら一覧に出す

各行:

```
N. <要約>（推奨 | 任意 | 無視）
   - 誰: <login>
   - 場所: <path>:<line> （なければ PR 全体）
   - 理由: <妥当性判断の一言>
```

| ラベル | 意味 |
|---|---|
| 推奨 | 妥当。対応した方がよい |
| 任意 | 一理あるが必須ではない。好み・方針次第 |
| 無視 | **推奨アクションが無視**。一覧には必ず残す。的外れ・方針不一致・ノイズ |

最後に必ず聞く:

```
どれに対応しますか？番号で指定してください (例: 1+3)
対応しない場合は「なし」
```

**この問いの前にコードを編集しない。**

### 4. 指定された指摘だけ直す

- 指定番号のみ修正する
- 指定外・「なし」は触らない
- 修正範囲は指摘の意図に必要な最小限
- 終わったら何をどう変えたか番号ごとに短く報告する

### 5. 修正後（デフォルトでやらないこと）

次は **ユーザーが明示したときだけ**:

- commit / push
- レビュースレッドへの返信
- conversation の resolve
- 追加の PR 操作

## やること / やらないこと

| やること | やらないこと |
|---|---|
| `gh` で PR レビューを読む | 番号指定前にコードを直す |
| 未対応の指摘を一覧に出す（無視含む） | 「無視」を一覧から消す |
| 対応済みの指摘は一覧から外す | 対応済みを一覧に残す |
| 妥当性（推奨/任意/無視）を付ける | 指定外の指摘を直す |
| 番号指定分だけ最小修正する | 指摘と無関係なリファクタ・整形・依存更新 |
| 修正内容を番号ごとに報告する | 勝手に commit / push / 返信 / resolve |
| PR が特定できないとき聞く | 別 PR・別ブランチを推測で触る |
| | 新規 PR 作成・レビュアー追加・approve 代行 |
| | 「ついで」のテスト追加や API 変更（指摘に含まれないもの） |

## サンプル

```
assistant:
以下の指摘がありました:

1. `l` は `line` にした方がよい（推奨）
   - 誰: copilot-pull-request-reviewer
   - 場所: src/main.rs:42
   - 理由: 1文字名で意図が読めない
2. このブロックを関数に切り出す提案（任意）
   - 誰: alice
   - 場所: src/main.rs:50-80
   - 理由: 可読性は上がるが必須ではない
3. 全公開 API にコメントを追加（無視）
   - 誰: bot
   - 場所: PR 全体
   - 理由: 方針上、自明な API にコメントを要求しない。ノイズ

どれに対応しますか？番号で指定してください (例: 1+3)
対応しない場合は「なし」

user:
1

assistant:
1 に対応する。src/main.rs の `l` を `line` にリネームした。
```
